# 涂鸦精灵（painting-sprite）设计文档 v2.0

> 日期：2026-09-29
> 状态：已确认（头脑风暴定稿，替代 v0.1 商业方案）
> 产出方式：superpowers:brainstorming 四轮问答验证

## 1. 定位与目标

**一句话**：给自家 3-6 岁孩子做的魔法涂鸦 App——画出来的东西，许个愿就活过来。

| 定位要素 | 决策 | 影响 |
|---|---|---|
| 项目性质 | **家庭项目**，不是商业产品 | 砍掉后端网关、订阅 IAP、配额计费、算法备案、家长门 |
| 用户 | 3-6 岁学龄前儿童 | 零文字 UI、全语音交互、超大按钮、8 秒耐心设计 |
| 预算 | **体验优先，不敏感** | 云端最好的模型拉满，不自建 GPU 省钱 |
| 涂色形态 | **App 内直接涂色** | 砍掉打印链路 + 拍照回传 + 透视校正 + 抠图 |
| 平台 | iOS/Android/macOS/Windows 单码库 | iPad 一等公民，桌面端是演示场 |
| 成本上限 | ≈ ¥1200/月（每天 10 次许愿拉满） | 真心疼了在设置里限流，架构不变 |

**成功标准**：孩子能独立完成"说线稿 → 涂色 → 许愿 → 看动画"全流程，全程不需要爸爸介入，且任何环节翻车都不哭。

## 2. 产品设计：三屏核心

```
┌──────────────────────────────────────────────────┐
│  ① 画画屏        ② 涂色屏         ③ 魔法屏        │
│  自由涂鸦        说话生成线稿      许愿变动画       │
│  大画笔大色盘    大色块填充        语音+预设按钮     │
└──────────────────────────────────────────────────┘
```

### 2.1 画画屏（自主涂鸦）
- 画笔（3 档粗细）、12 色大色盘、橡皮、撤销、清空、保存
- 触摸目标全部 ≥64pt（圆肌肉友好），图标零文字
- 完成后一键"送去施魔法"→ 进入魔法屏

### 2.2 涂色屏（生成线稿 → 填色）
- 大麦克风："我要一只小恐龙" → 生成 2 张线稿大图二选一
- **泛洪填充涂色**：点哪个区域，哪个区域变颜色，颜色可覆盖
- 内置 **20 张经典线稿库**（恐龙/小猫/公主/火箭/独角兽…）作为离线兜底和快捷入口

### 2.3 魔法屏（许愿变 5 秒动画）
- **许愿双通道**：
  - 语音：按住大麦克风说愿望（"让它跳起舞来！"）
  - 预设按钮：4 个愿望大图标（跳舞🕺 / 飞起来🕊️ / 唱歌🎤 / 奔跑🏃）——发音不准或害羞时的兜底
- **等待期魔法演出**（核心技术亮点）：视频生成需 30s~2min，学龄前儿童等不了——按下许愿瞬间，本地动画引擎让涂鸦先扭起来 + 魔法粒子特效 + TTS 讲故事（"小精灵正在给小恐龙施魔法呢…"），把技术延迟包装成魔法仪式感
- 完成后全屏播放（视频自带音效）+ 撒花庆祝 + 自动存入相册

### 2.4 作品相册
本地目录直存：原图 PNG + 愿望文本 + 动画 MP4。无云端、无账号、无同步。家长手动备份。

## 3. 技术架构

### 3.1 总览

```
Flutter 四端单码库
│
├─ 本地层（永不下班）
│   ├─ 画板引擎：笔画模型 List<Stroke> + CustomPainter
│   │            泛洪填充（scanline + tolerance + 抗白边扩边）
│   ├─ 本地动画引擎：果冻跳/摇摆/旋转/果冻抖动 + 粒子特效
│   │            （等待期演出 + 云端失败兜底，<1s 出效果）
│   ├─ TTS：flutter_tts 调系统语音（兜底，免费）
│   └─ 相册：本地文件 + 元数据 JSON
│
└─ AI 直连层（无自建后端，密钥放本地配置文件，永不提交仓库/永不直接上架）
    ├─ 语音识别 ASR ──── 豆包 ASR（童音容错好，≈¥0.003/次）
    ├─ 愿望理解 LLM ──── GLM-4-Flash 免费档：
    │                    一箭三雕：愿望分类 + 中译英 + 生成视频提示词
    ├─ 线稿生成 ──────── 豆包 Seedream 5.0 pro（¥0.30/张，质量优先）
    ├─ 视频生成 ──────── 可灵 3.0 有声版 720p（¥0.8/秒，5s=¥4，
    │                    视频自带音效——小恐龙会吼叫）
    └─ 童声旁白 TTS ──── 云端 TTS（¥0.05/次，讲魔法故事）
```

### 3.2 关键决策及理由

| 决策 | 理由 |
|---|---|
| 无后端，客户端直连 AI API | 家庭使用无多用户风险；省掉服务器运维；**纪律：密钥本地 config + gitignore，此包不上架** |
| 云端视频做主路径（非本地骨骼动画） | 体验优先 = 效果天花板优先；可灵 3.0 有声版是本地动画永远给不了的惊叹；不敏感预算下自部署 GPU 属于反向优化，砍 |
| 视频提示词在客户端由 LLM 生成 | 一次调用完成分类/翻译/提示词工程（童言→英文视频提示词），省调用次数 |
| GLM-4-Flash 免费档 | 改写任务极简单，免费档绰绰有余 |
| 线稿生成用 pro 不用 flash | 线条闭合率直接影响涂色体验，质量敏感，¥0.18 的差价值得 |
| 本地动画引擎双职能 | 等待期演出（把 30s-2min 延迟变成魔法仪式）+ 降级兜底（翻车不哭），一份代码两个价值 |

### 3.3 核心链路数据流

```
【涂色链路】
说话 → ASR 文本 → LLM 改写线稿提示词（儿童涂色书风格模板）
  → Seedream 生成 2 张 → 孩子二选一 → 泛洪涂色 → 完成进魔法屏
  失败 → 重试 1 次 → 内置线稿库兜底

【许愿链路】
按住说话 → ASR → LLM（分类+译英+视频提示词）
  → 立即启动本地魔法演出（涂鸦扭动+粒子+TTS 故事）
  → 可灵图生视频（作品图+提示词，720p 5s 有声）异步轮询
  → 完成 → 全屏播放 + 撒花 + 存相册
  超时 3min → 本地动画兜底播放 + TTS 圆场
```

### 3.4 降级阶梯（任何环节翻车，孩子永远不面对"失败"）

| 翻车点 | 兜底 |
|---|---|
| 语音没听清 | TTS"再说一遍好不好？" + 4 个预设愿望大按钮 |
| 线稿生成失败 | 自动重试 1 次 → 内置 20 张线稿库（离线可用） |
| 视频超时 3 分钟 | 本地动画兜底播放 + TTS："小精灵的魔法还在路上，它先自己扭一扭！" |
| 完全断网 | 纯本地模式：画画 + 内置线稿涂色 + 本地动画，App 永不白屏摆烂 |

## 5. 里程碑（4 周，业余节奏）

| 周 | 交付 | 验收 |
|---|---|---|
| W1 | 四端工程 + 画板（笔画/色盘/撤销/保存）+ 本地动画引擎 | 任意涂鸦一键"扭起来"，<1s |
| W2 | 线稿生成（语音→线稿二选一）+ 泛洪涂色 + 内置线稿库 + TTS | 说话出线稿，涂色不漏色，断网能玩 |
| W3 | 许愿全链路（ASR→LLM→可灵视频）+ 降级阶梯 + 相册 | 语音许愿出 5s 有声动画，拔网线不哭 |
| W4 | 魔法演出打磨（粒子/音效/撒花）+ 四端验收 + 限流开关 | 孩子独立完成全流程，全程无大人介入 |

## 6. 测试策略

- **单元测试**：笔画模型、撤销栈、泛洪填充算法（含抗锯齿边界 case）、提示词模板拼装
- **Widget 测试**：三屏导航流、涂色交互、许愿按钮态
- **Mock AI 层**：AiService 接口抽象，本地 Mock 实现（假线稿/假视频/固定延迟），跑 CI 不花钱
- **手动验收**：四端各过一遍核心链路 + 断网演练 + 孩子实测（终极验收）

## 7. 风险清单

| 风险 | 概率 | 应对 |
|---|---|---|
| 孩子发音不清 ASR 识别率低 | 高 | 预设愿望按钮双通道；ASR 结果给 LLM 模糊匹配纠正 |
| 可灵把儿童涂鸦理解偏（生成奇怪内容） | 中 | LLM 提示词增强画面描述；生成前预览；失败重试；本地兜底 |
| 线稿线条不闭合涂色漏色 | 中 | 提示词强约束 + pro 模型 + 二选一机制 |
| 桌面端（macOS/Windows）麦克风权限/语音栈差异 | 中 | W1 就在四端验证录音与 TTS，早暴露早治疗 |
| 月底账单惊喜 | 低 | 硬上限熔断提醒 + 设置限流 |
| 密钥泄露 | 低 | 本地 config + .gitignore + 绝不上架此包 |

## 8. 与 v0.1 的差异（决策审计记录）

| v0.1（商业方案） | v2.0（本设计） | 变更原因 |
|---|---|---|
| 商业产品，DAU/订阅/备案全家桶 | 家庭项目，无任何商业化组件 | 头脑风暴确认目标 |
| 三层动画引擎（含自部署 GPU） | 云端视频主路径 + 本地动画兜底 | 体验优先，省钱无意义 |
| 打印线稿→纸上涂色→拍照回传 | App 内直接涂色 | 用户确认，砍掉全链路最脆弱环节 |
| 手动输入愿望 | 语音 + 预设按钮双通道 | 3-6 岁不识字 |
| 后端网关 + 供应商可插拔 | 客户端直连 + 配置文件切供应商 | 无多用户/计费需求 |
| 成本设计围绕毛利 | 成本上限 ¥1500 熔断 | 家庭预算逻辑 |

**v0.1 的价值保留**：四端可行性分析（§2）、API 行情核实（2026-09 价格）、语音三件套成本结论——这些事实层内容继续有效，作为附件存档于 `docs/可行性分析与技术方案.md`。
